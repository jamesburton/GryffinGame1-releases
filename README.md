# Tank Battle — releases

Public downloads for **Tank Battle**, a top-down roguelite tank game by James Burton.

This repository contains **release builds only**. The source code is private and is not published here.

## Download

Get the latest build from the [Releases page](https://github.com/jamesburton/GryffinGame1-releases/releases/latest).

| Platform | File |
|---|---|
| Windows x64 | `TankBattle-<version>-win64.zip`: unzip and run `TankBattle.exe` |
